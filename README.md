

## Описание проекта
Проект **Sprint-4** предназначен для автоматизированного тестирования веб-приложения [Яндекс Самокат](https://qa-scooter.praktikum-services.ru/).  
Тесты написаны с использованием **JUnit 4, Selenium WebDriver** и **Page Object Model (POM)**.

## Используемые технологии
| Технология        | Версия       | Описание |
|------------------|-------------|----------|
| **Java**        | 11          | Основной язык программирования |
| **JUnit**       | 4.13.2      | Фреймворк для тестирования |
| **Maven**       | 3.9.0       | Управление зависимостями |
| **Selenium**    | 4.11.0      | Инструмент для UI-тестирования |
| **WebDriverManager** | 5.5.3  | Автоматическое управление драйверами браузеров |

## Установка и настройка
### 1️. Клонирование репозитория
```
sh
```

git clone https://github.com/your-repo/AutoTestingForYandex.git
cd AutoTestingForYandex

### 2. Установка зависимостей
Запускать в корневой папке проекта:
```
mvn clean install
```

### 3. Запуск тестов
Для запуска всех тестов:
```
mvn clean test
```

## Структура проекта
```
src
│── main
│   ├── java
│   │   ├── pages         # Page Object классы для работы с веб-элементами
│   │   ├── utils         # Вспомогательные классы (Config, DriverManager)
│── test
│   ├── java
│   │   ├── tests         # Автотесты
│   │   ├── BaseTest      # Базовый класс для тестов
│── pom.xml               # Файл конфигурации Maven
│── .gitignore            # Файлы, игнорируемые Git
```

## Описание тестов


| Класс тестов      | Назначение                                      |
|-------------------|------------------------------------------------|
| `FAQTests`       | Проверяет корректность раскрытия FAQ           |
| `MainPageTests`  | Проверяет кнопки "Заказать" на главной странице |
| `OrderPageTests` | Проверяет процесс оформления заказа            |


## Известные проблемы

❗ В Chrome есть баг, который не позволяет оформить заказ – тест должен падать с ошибкой.

❗ В логах могут быть предупреждения CDP, они не влияют на тестирование.
